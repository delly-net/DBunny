# 开始使用 DBunny

本文档介绍如何快速开始使用 DBunny 数据库抽象层。

## 安装

选择你需要的数据库提供者包并安装：

```
# 核心包
dotnet add package Delly.DBunny.Core

# SQLite
dotnet add package Delly.DBunny.Sqlite

# MySQL
dotnet add package Delly.DBunny.MySql

# PostgreSQL
dotnet add package Delly.DBunny.PostgreSql

# Oracle
dotnet add package Delly.DBunny.Oracle
```

## 基本用法

### 1. 创建数据库连接

```csharp
// SQLite
var sqliteConnection = new SqliteConnectionDefine()
    .WithDataSource("data.db");

// MySQL
var mysqlConnection = new MySqlConnectionDefine()
    .WithServer("localhost")
    .WithDatabase("mydb")
    .WithUserId("root")
    .WithPassword("password");

// PostgreSQL
var pgConnection = new PostgreSqlConnectionDefine()
    .WithHost("localhost")
    .WithDatabase("mydb")
    .WithUsername("postgres")
    .WithPassword("password");

// Oracle
var oracleConnection = new OracleConnectionDefine()
    .WithDataSource("localhost:1521/ORCL")
    .WithUserId("user")
    .WithPassword("password");
```

### 2. 配置提供者工厂

```csharp
var factory = new DefaultDbProviderFactory();
factory.Append(new SqliteProvider());
factory.Append(new MySqlProvider());
// 添加其他提供者...
```

### 3. 执行查询

```csharp
var provider = factory.GetProvider("SQLITE");

// 创建 SQL
var sql = new Sqled("SELECT * FROM Users WHERE Name = @name");
sql.Set("name", "John");

// 异步读取
var dataSet = await provider.ReadAsync(connection, sql);

// 同步读取
var data = provider.Read(connection, sql);
```

### 4. 使用 Fluent API

```csharp
var sql = new Sqled("SELECT * FROM Users")
    .Append(" WHERE Age > @minAge")
    .Append(" AND Status = @status")
    .Set("minAge", 18)
    .Set("status", "Active");
```

## 支持的操作

- 数据库元数据查询（架构、表、列、索引）
- 参数化查询
- 同步和异步执行
- 多数据库类型支持
