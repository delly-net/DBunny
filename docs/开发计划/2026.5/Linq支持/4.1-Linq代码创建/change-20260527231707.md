## 变更内容

### 1. 架构调整

**原设计**：简单的 DbExpressionVisitor 表达式访问器模式
**新设计**：参考 Eazy.Data 的完整表达式系统架构
- 添加 `IQueryExpressionRelay` 表达式中继接口
- 添加 `CompilerFactory` 编译器工厂
- 添加 `StatementBuilder` 表达式编译器构建器
- 添加 `VariableBuilder` 变量构建器
- 添加完整的表达式类型系统

### 2. AOT 兼容

**原设计**：无 AOT 兼容设计
**新设计**：添加 AOT 兼容特性
- 使用 `DynamicallyAccessedMembers` 标记需要动态访问的类型
- 使用 `RequiresUnreferencedCode` 标记需要反射的代码
- 使用 `UnconditionalSuppressMessage` 抑制 AOT 警告

### 3. 表达式系统

**原设计**：仅基础表达式访问
**新设计**：完整的表达式类型体系
- `QueryRootExpression` - 根表达式
- `QueryWhereExpression` - Where 表达式
- `QuerySelectExpression` - Select 表达式
- `QueryOrderByExpression` - OrderBy 表达式
- `QuerySelectManyExpression` - SelectMany 表达式
- `QueryGroupByExpression` - GroupBy 表达式

### 4. 建模支持

**原设计**：未提及实体建模
**新设计**：适配 DBunny 的建模系统
- 创建 `IEntityModel` 实体模型接口
- 创建 `IEntityModelFactory` 实体模型工厂
- 支持表名映射和列名映射

### 5. 目标框架

**原设计**：netstandard2.0;net5.0;net8.0
**新设计**：保持不变

## 变更原因

根据需求补充文档的要求，需要参考 `Eazy.Data` 项目的实现进行移植和 AOT 兼容改造。原设计过于简单，无法满足 AOT 兼容和完整 LINQ 功能支持的需求。

## 可能产生的影响

1. **实现复杂度增加**：需要实现更多的接口和类，代码量增加
2. **学习成本增加**：新的架构需要团队成员学习理解
3. **AOT 支持**：可以为 .NET 8.0 提供 AOT 编译支持
4. **功能完整性**：支持更完整的 LINQ 操作
5. **扩展性增强**：基于新的架构可以更容易地扩展新的 LINQ 操作
