## 变更内容

### 1. 实体建模接口来源

**原设计**：在 `Delly.DBunny.Linq.Dependency` 中定义 `IEntityModel` 和 `IEntityModelFactory` 接口
**新设计**：使用 `Delly.Modeling` 包中的接口
- 移除 `Dependency/IEntityModel.cs`
- 移除 `EntityModeling/IEntityModelFactory.cs` 和 `EntityModeling/DefaultEntityModelFactory.cs`
- 添加 `Delly.Modeling` 包引用到 `Delly.DBunny.Linq.csproj`
- 使用 `using Delly.Modeling;` 引入外部接口

### 2. 项目依赖调整

**原项目配置**：
```xml
<ItemGroup>
  <ProjectReference Include="..\Delly.DBunny.Core\Delly.DBunny.Core.csproj" />
</ItemGroup>
```

**新项目配置**：
```xml
<ItemGroup>
  <ProjectReference Include="..\Delly.DBunny.Core\Delly.DBunny.Core.csproj" />
  <PackageReference Include="Delly.Modeling" Version="2026.5.18" />
</ItemGroup>
```

### 3. 目录结构调整

移除的文件/目录：
- `Dependency/IEntityModel.cs`
- `EntityModeling/` 目录及其下所有文件

### 4. 接口命名空间调整

**原命名空间**：`Delly.DBunny.Linq.Dependency`
**新命名空间**：`Delly.Modeling`（外部包）

## 变更原因

根据需求补充文档第5条，`IEntityModel` 与 `IEntityModelFactory` 已在 `Delly.Modeling` 包（v2026.5.18）中实现，并被 `Delly.DBunny.Core` 引用。应复用现有接口而非重复定义。

## 可能产生的影响

1. **依赖管理**：新增对 `Delly.Modeling` 包的依赖
2. **兼容性**：需要确保与 `Delly.Modeling` 包版本兼容
3. **代码量减少**：移除重复的接口定义，减少维护成本
4. **一致性**：与现有 `Delly.DBunny` 项目保持一致的建模方式
