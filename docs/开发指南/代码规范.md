# 代码规范

本文档定义 DBunny 项目的编码规范和约定。

## 命名约定

### 常量

- 常量使用 **UPPER_CASE** 命名，单词间用下划线分隔
- 数据库类型常量使用 `DATABASE_TYPE` 名称
- 连接参数常量使用 `_KEY` 后缀

```csharp
// 正确
public const string DATABASE_TYPE = "SQLITE";
public const string DATA_SOURCE_KEY = "Data Source";
public const string CONNECTION_TIMEOUT_KEY = "Connection Timeout";

// 错误
public const string DatabaseType = "SQLITE";
public const string dataSourceKey = "Data Source";
```

### 接口

- 接口使用 `I` 前缀
- 名称清晰表达其职责

```csharp
public interface IDbProvider { }
public interface ISqlProvider { }
public interface IDbConnectionFactory { }
```

### 类

- 提供者类以数据库类型命名，不使用前缀
- 连接定义类以数据库类型 + `ConnectionDefine` 命名
- SQL 提供者类以数据库类型 + `SqlProvider` 命名

```csharp
public class SqliteProvider : IDbProvider { }
public class SqliteConnectionDefine : BaseConnectionDefine { }
public class SqliteSqlProvider : ISqlProvider { }
```

### 扩展类

- 扩展方法类以原类型 + `Extension` 命名

```csharp
public static class SqledExtension { }
public static class DbProviderExtension { }
public static class SqliteConnectionDefineExtension { }
```


## 目标框架

所有项目必须支持以下目标框架：

```xml
<TargetFrameworks>netstandard2.0;net5.0;net8.0</TargetFrameworks>
```

- **netstandard2.0**：最大兼容性
- **net5.0**：支持可空引用类型
- **net8.0**：支持 AOT 编译

## 可空引用类型

对于 .NET 5.0+ 目标框架，启用可空引用类型：

```xml
<Nullable>enable</Nullable>
```

## 添加新数据库提供者

1. 创建新项目（如 `Delly.DBunny.YourDb`）
2. 创建连接定义类继承 `BaseConnectionDefine`
3. 实现 `IDbProvider` 接口
4. 实现 `ISqlProvider` 接口
5. 设置相同的 `TargetFrameworks`
6. 添加项目引用到 `Delly.DBunny.Core`

详细步骤请参考主 [CLAUDE.md](../../CLAUDE.md) 文档。
