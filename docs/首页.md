# DBunny

DBunny 是一个轻量级的 .NET 数据库抽象层，为多种数据库类型提供统一的 API。它使用提供者模式实现数据库特定的实现，同时保持公共接口的一致性。

## 特性

- 支持多种数据库：SQLite、MySQL、PostgreSQL、Oracle
- 统一的 API 接口
- 多框架支持：.NET Standard 2.0、.NET 5.0、.NET 8.0
- 异步操作支持
- Fluent API 构建 SQL
- 数据库元数据查询

## 快速开始

```csharp
// 创建连接定义
var connection = new SqliteConnectionDefine()
    .WithDataSource("mydb.db");

// 获取提供者
var factory = new DefaultDbProviderFactory();
factory.Append(new SqliteProvider());
var provider = factory.GetProvider("SQLITE");

// 执行查询
var sql = new Sqled("SELECT * FROM Users");
sql.Set("name", "John");
var result = await provider.ReadAsync(connection, sql);
```

## 项目结构

- **Delly.DBunny.Core** - 核心库，包含接口和基础类型
- **Delly.DBunny.Sqlite** - SQLite 提供者实现
- **Delly.DBunny.MySql** - MySQL 提供者实现
- **Delly.DBunny.PostgreSql** - PostgreSQL 提供者实现
- **Delly.DBunny.Oracle** - Oracle 提供者实现
