# Code Review - DBunny

DBunny 项目的代码审查技能。

## 使用方法

```
/review
```

## 功能

1. **审查当前分支的更改**
   - 运行 git diff 命令查看更改
   - 检查代码风格、架构一致性和潜在问题

2. **审查检查项**
   - 目标框架一致性：所有项目应支持 netstandard2.0;net5.0;net8.0
   - XML 文档：所有公共函数必须有完整的 XML 文档注释
   - 约定遵循：常量使用 UPPER_CASE，参数常量使用 _KEY 后缀
   - 数据库提供者一致性：实现模式应与现有提供者一致
   - 空值引用类型：.NET 5.0+ 应启用可空引用类型

3. **输出审查报告**
   - 列出发现的问题
   - 提供改进建议
   - 标记关键问题

## 输出

返回代码审查报告。
